# dcsync
BOF to dcsync a single account's cred material

## Usage
```
dcsync [Target DN] [Domain DN] [Domain Controller]

Args:
- Target DN         : wide string/Z
- Domain DN         : wide string/Z
- Domain Controller : wide string/Z
```
