# SessionHop
BOF port of [SessionHop](https://github.com/3lp4tr0n/SessionHop) by [@AndrewOliveau](https://x.com/AndrewOliveau) to start a process in the session of another user.

## Usage
```
sessionhop [sessionId] [filePath]

Args:
- sessionId : int/i
- filePath  : wide string/Z
```
